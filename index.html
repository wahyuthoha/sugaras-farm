Pengaturan & data

Atur identitas SUGARA’S dan kelola salinan data usaha.

Privasi data: versi ini menyimpan data di browser/perangkat yang digunakan. Ekspor cadangan secara berkala dan simpan file di tempat aman. Sinkronisasi cloud belum diaktifkan.

Informasi versi

SUGARA’S Farm Management · Versi lokal awal. Fitur yang tersedia: pencatatan keuangan, data sapi, produksi susu, pakan/persediaan, kesehatan/reproduksi, aset usaha, ekspor CSV, serta cadangan/pemulihan JSON. Aplikasi belum memiliki akun pengguna, database cloud, sinkronisasi otomatis, atau perhitungan penyusutan aset.
